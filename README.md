# Agentic Healthcare Assistant

## Overview

This Streamlit app simulates a virtual medical assistant that:

- Plans and executes healthcare tasks
- Books appointments
- Retrieves medical history
- Summarizes treatment options
- Displays memory traces and tool logs

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/agentic-healthcare-assistant.git
   cd agentic-healthcare-assistant
   ```
